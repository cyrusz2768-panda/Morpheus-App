# 网页与音乐链接附件

更新：2026-11-14。Android / iOS 共用 Dart 功能。用户已确认iOS验收通过并授权发布，交付与CI结果见[项目状态](PROJECT_STATUS.md)；Android已完成构建检查，音乐播放器不在本轮范围。

## 使用与记录规则

记录页正文下方「+」菜单依次为添加图片、添加网页链接、添加音乐链接。输入 HTTP(S) 分享地址和可选标题，保存后展示链接卡片；不填标题时显示地址。点击卡片打开，右侧更多菜单提供打开、修改、删除。修改保留类型与稳定ID；清空标题恢复地址显示，取消不改原记录。表单只接受单独的网址，复制的歌曲分享介绍需先去掉；可直接填写`example.com/path`，也可带`www.`或完整`http(s)://`；省略协议时补`https://`，不擅自补`www.`。

正文中的网页地址也会显示为主题紫色，短按使用同一App内浏览器打开。允许省略协议和`www.`；原文不自动补字、不额外生成附件。识别只在本地做格式校验，不查询DNS或请求网页，因此不保证网站实际存在或可访问。无效格式保持普通文字，不显示校验提示；邮箱、其他协议、坏端口和常见文件名不当作网页。支持ASCII域名及国际域名的`xn--`编码。中文标点不计入地址，路径中的成对括号保留。

编辑框保留原生长按选字、拖动与输入法组合行为；组合输入尚未确认的片段暂不高亮/打开。点击只检查真实文字区域，行尾空白不会误触。使用不含手势的TextSpan绘制，再由TextField自身的点击回调和字形盒确认落点，避开Flutter可编辑语义树不支持Span手势的限制。

网页与音乐链接按日期保存。**只有链接也算记录**，进入历史、月历与统计活动；同日文字、图片和多个链接仍只贡献一个日期。状态、评分、因素保持独立，不从链接推断。清空文字或移除图片不会删除链接；删除最后链接时仍保留已有正文、图片、反馈或完成标记，全空才删除日期行。正文搜索继续只查正文，不扩展为链接搜索。

卡片、加号和后续按钮沿用图片验收后的无外框自然排版，只滚动整页。附件不抓取网站标题、封面或音乐预览；只有用户主动打开时才联网。

## 网页与音乐打开方式

使用官方 [url_launcher](https://pub.dev/packages/url_launcher) 6.3.3，原锁定依赖不升级。网页使用系统提供的App内浏览器：iOS SFSafariViewController，Android Custom Tabs；支持网页返回和关闭。Android没有Custom Tabs或打开失败时采用内部WebView，普通网页不主动退到独立浏览器App。Android主清单声明INTERNET及Custom Tabs能力查询，无新增运行时授权弹窗。

初始地址为Apple App Store、Google Play、华为或三星商店时明确外跳。正常App内浏览器中网站的商店跳转、App Links、下载及登录行为由系统和目标网站处理，不自建完整浏览器。极少数没有Custom Tabs的Android使用内部WebView回退，该回退不会逐次拦截商店HTTP网址重定向，商店网页可能仍留在内部；本轮不承诺每个网站、每种短链或重定向链都相同。

音乐先尝试非浏览器应用处理原始HTTP(S)地址。iOS使用Universal Links，Android 11+使用非浏览器Intent；App已安装且关联该链接时可唤起。失败时回App内网页，不修改分享地址的query/fragment、不猜测网易云/QQ/酷狗等未公开的私有scheme。Android 7–10缺少非浏览器Intent标记，因此有小型原生桥接：排除通用网页处理包，只尝试实际音乐链接的其余候选软件，无可用候选时回内部浏览器。桥接失败也留在内部。厂商链接关联、用户默认设置和软件版本会影响结果，需用装有对应软件的真机验证；模式顺序单元测试不代表每款音乐App均已实际唤起。

没有音乐软件或使用模拟器时，网页回退属于预期行为。当前不接入流媒体SDK、歌词或播放器，不在启动/保存附件时请求音乐权限。

## 数据流与升级保护

`链接表单/卡片 → DreamEditorController → DreamRepository / ILinkOpener → url_launcher / Android旧版桥接`。页面不直接写数据库或调用原生平台。

数据库v4仅在原 `dream_records` 表追加 `links TEXT NOT NULL DEFAULT '[]'`，每项保存稳定id、url、可选title、web/music类型。v1/v2/v3升级链均保留，旧正文、日期、UTC时间、反馈及图片元数据不改写。相册图片仍在原私有目录，链接不写图片文件。

链接进入同一800ms防抖与串行保存队列。完整快照含正文、反馈、图片和链接，写入中继续编辑会保存最新版本。仓库省略links保留旧值，显式空列表才清除；损坏JSON、重复id或不合法URL视为读取失败，不默认为空附件继续覆盖。

表单记录原日期和加载版本；通知切日或切日再返回后，旧表单不写入当前记录。打开链接前等待最新草稿保存，失败保留草稿并阻止打开；等待后再次核对日期版本和链接id/地址；正文链接核对UTF-16区间、原文和目标地址，避免旧操作打开已被改掉的链接。旧版已保存的显式HTTP附件仍按原规则解码，新增格式校验不会使旧记录读失败。本次正文识别不变更v4数据库或依赖。

## Apple Music后续播放

iOS以后可以通过 [MusicKit](https://developer.apple.com/musickit/) 的 [ApplicationMusicPlayer](https://developer.apple.com/documentation/musickit/applicationmusicplayer) 在Morpheus内控制播放，不必跳到Music App。后续需要开启MusicKit、通过用户授权，并检查订阅播放能力及曲目地区可用性；完整订阅曲库播放需要相应有效订阅。Flutter可通过原生平台接口接入Swift。后台播放配置另行验证，本轮不提前加入音乐授权或密钥。
