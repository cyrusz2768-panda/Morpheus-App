# 每日梦境与睡眠反馈

2026-11-12 在 `0c3a00a` 上开发，Android / iOS 共用 Dart 流程；开发阶段按用户要求仅本地交付；用户同日确认 iOS 模拟器验收通过，随后授权同步 GitHub 主线及文字库。平台检查、模拟器实际操作与用户验收分别记在 [项目状态](PROJECT_STATUS.md)。统计升级另行安排。

## 使用流程

1. 当天首次记录询问“你昨晚做了什么梦？”，选择好梦／噩梦进入正文；没记住／没做梦跳过正文。底部“跳过”不填写分类，直接进入正文。
2. 正文保持 800ms 自动保存。“继续”或“跳过”先保存现有草稿，再进入睡眠评分；正文步骤的“梦境状态”可重新选分类。
3. 评分范围为 1–5 分，选择后进入因素多选。“跳过”直接结束，评分未填保持 `null`，不会记为 0 分。
4. 因素为压力、情绪、时事、旅行、睡前屏幕、咖啡因、作息变化、环境、身体健康、不确定。选择独立自动保存；“完成”和“跳过”都先保存，再结束。跳过不删除已经填写的内容。
5. 结束页展示告别语，下半屏查看正文，继续向下滚动查看评分和因素；“修改”可以重新填写对应项。没记住／没做梦时，已有正文折叠保存，切回好梦／噩梦可继续编辑。

已完成当天再次打开时直接恢复结束页；未完成当天重新打开从分类开始，已保存的正文和反馈仍在。历史日期已有记录直接查看结束页，空日期可以补记。跨午夜不自动切换正在编辑的日期。

## 数据与保存

- `DreamEntry` 持有正文和 `DailyFeedback`；状态、可空评分和因素互相独立，不从好梦／噩梦推算评分。
- 日期继续使用醒来后填写的本地当天 `yyyy-mm-dd`，不因问题里“昨晚”减一天；创建与更新时间仍为 UTC。
- 数据库版本由 1 升至 2，在原表追加 `dream_mood`、`sleep_score`、`sleep_factors`、`flow_completed`。状态和因素保存枚举稳定标识，因素用 JSON；迁移不改旧正文、日期及时间，新反馈保持未填写。
- 正文非空或任一反馈存在，就属于有效记录。无正文的反馈也进入历史和日历圆点；搜索仍只搜索正文。
- 全部跳过时仅保存完成标记，以便重开恢复结束页；它不作为有效反馈出现在历史、日历或统计中。评分保持 `null`。
- 只有正文、反馈和完成标记都为空才删除该日期行。清空正文不会连带清除反馈。
- 正文与反馈经同一串行保存队列写入完整快照。导航、收起正文、完成步骤前等待最新写入；失败保留草稿和原步骤，可重试。后台保存仍是尽力行为，不能保证系统强杀前最后输入落盘。
- 本轮统计继续仅按非空正文计算记录天数，不展示状态、评分或因素统计，不把主观反馈当作客观睡眠数据。

## 验收建议

请用人工测试内容，保留已有数据，不卸载或清空模拟器。

- 分别从 App 与每日提醒打开当天，检查四个分类与底部跳过。
- 好梦／噩梦输入正文后继续，选择任意评分及多个因素，完成后向下滚动查看。等“已保存”再完整退出重开。
- 没记住／没做梦应直接进入评分；跳过评分后显示结束页，历史和日历可以找回无正文反馈。
- 全部跳过、正文为空时显示告别语，重开仍是完成页，历史与月历不新增空反馈。
- 已有正文切换没做梦后应仅收起，切回好梦后内容完全保留。新字段不改变旧梦境。
- 修改评分不改变状态或正文；跳过评分没有 0 分。评分后跳过因素，也应保留评分。
