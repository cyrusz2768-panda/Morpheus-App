# 图片导出与分享

更新日期：2026-11-14。本轮为 Android / iOS 共用的本地长图功能，用户验收与发布状态以 [项目状态](PROJECT_STATUS.md) 为准。

## 使用方法

1. 打开有文字、图片或链接的日期，点击右上角三个点，再选“分享完整记录”。任意记录步骤均可进入。
2. App 等待最新草稿保存，然后生成长图预览；失败时保留原记录和草稿，可以重试。仅睡眠反馈没有本轮可分享内容，会提示为空。
3. 上下滚动预览，双指缩放查看细节；点击“保存相册”或“系统分享”。预览、相册与分享使用同一版 PNG，预览期间不重新读取旧记录。
4. 首次保存时按系统提示授予添加照片权限。拒绝后仍能系统分享；可在系统设置允许后重试。只有系统确认相册写入后才显示“已保存到相册”。取消分享不会显示成功或失败。

## 内容与二维码

长图顺序为应用名、日期、完整正文、用户图片、网页/音乐标题及完整网址、底部二维码与说明。保留正文换行和空格，图片按原比例等宽展开，不裁切。图片不继承原文件的定位等 EXIF 元数据。

当前没有账号、云端记录网页或公开记录 URL。底部二维码离线编码日期与文字摘要（正文摘要最多360个 UTF-8 字节，按紧凑二维码密度可进一步缩短，Unicode码点完整）；左侧两行依次为“夜行者·Morpheus”“扫描右侧二维码，查看日期与文字摘要”，右侧160px二维码。二维码摘要可能省略，长图正文不因此缩短。仅图片或链接时，二维码含日期及查看长图的说明。扫描器对离线文字二维码的显示方式由其实现决定，不保证跳到网页。

音乐当前只有链接附件，PNG 不包含音频或播放器。网页/音乐链接的类型、可选标题、完整 URL 与扫码提示在左，140px二维码在右。链接码从280px、底部码从320px各缩小一半边长，白底正方形面积缩至四分之一，左右间距24px，行高取两栏较大值。二维码保留四模块白边及至少2px/module；700字节以内且实际模块密度可容纳的URL配码，过长/过密网址完整排版并提示复制，不截断URL。不会抓取封面、下载音乐、访问短链服务或自动联网打开链接。

本轮不显示“分享夜行卡片”空入口。待推荐内容实现后再设计精简卡片，避免让用户点击没有内容的选项。

## 数据流与平台差异

`DreamEditorPage → flushPendingSave → DreamExportData快照 → IDreamExportRenderer → PNG预览 → IDreamExportOutput → 系统`

- 导航复用 `navigationActivityProvider`，等待图片导入与串行保存，检查读取失败和最新输入；保存失败留在编辑器，不用数据库旧值替换草稿。
- Canvas 先测量再绘制，输出宽900px、最高16000px。文件真实尺寸在解码前检查，按输出尺寸解码并释放；超出像素预算或缺图/损坏图报错，不输出残缺长图。记录本身不会被修改或截断。极长正文或多张竖图可能触及限制，后续可扩展分图导出。
- PNG 仅在用户按保存/分享时写入私有临时目录 `dream_exports`。保存后尝试删除临时文件；分享保留文件供接收方读取，下次导出回收一天前的 PNG，系统也可能回收缓存。原图和数据库不在清理范围。预览退出时停止后续生成步骤并驱逐对应位图缓存。
- iOS 通过 Photos `addOnly` 请求，仅在保存时申请添加照片权限；`NSPhotoLibraryAddUsageDescription` 独立于选择附件用途说明。分享使用系统面板，iPad传按钮位置作为popover锚点。
- Android10及以上使用 MediaStore 新建PNG，不申请媒体读取权限，`IS_PENDING`在复制完成后发布，失败删除未完成媒体行。Android API24–28仅保存时请求旧写权限，写入Pictures/Morpheus并等待媒体扫描。
- 本轮新增 `share_plus` 与纯Dart `qr`，原有锁定依赖不升级，不修改数据库schema（仍v4）。新增界面文字同步 ARB；2026-11-14用户确认iOS验收通过后已完成195条资源审校，分享23项接线齐全，仍仅中文。

## 验收建议

使用人工测试内容，不上传真实梦境、相册图片、导出PNG或模拟器截图到仓库。

- 在当天输入两段文字（含换行/emoji），防抖未满时立即分享，核对预览包含末尾输入。
- 从月历打开旧日期，分享并核对日期；在分类、正文和结束页都能从三个点进入。
- 添加横图和竖图，确认原图完整、无裁切；分别检查仅图、仅音乐及多链接记录。
- 滚到长图底部，扫码核对日期与摘要；音乐二维码应打开原链接。
- 保存相册，检查权限允许后的真实照片、拒绝后仍可分享；系统分享取消后回到预览。iOS模拟器的可用接收App有限，第三方App与Android相册权限仍需真机/相应系统验证。
- 返回编辑器核对原记录不变；仅反馈/空日期应提示没有可分享内容。不要以卸载或清数据测试升级。

自动测试覆盖摘要容量、真实PNG尺寸与图片比例、缺图与超限、相册桥接结果和临时文件、系统分享锚点与取消、保存竞态/失败保护、生成重试和窄屏大字号预览。实际测试数量、双端构建和手工操作以当轮日志为准，构建通过不等于用户或真机验收。
