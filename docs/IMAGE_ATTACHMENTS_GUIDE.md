# 梦境图片附件

更新：2026-11-13。本轮仅实现相册图片；链接附件尚未开发。Android 与 iOS 共用 Dart 实现。

2026-11-13 用户确认图片功能及展开布局的 iOS 模拟器验收通过（`53d0236`），授权上传GitHub；最终270项测试、格式、分析及双端构建通过。Android逐项人工验收和真机测试不因本次确认扩大记录。

## 使用

正文下方左侧的「+」打开上方菜单，目前只有「添加图片」。每次选择一张，可重复添加。缩略图使用相同可用宽度，左右各留少量相等间距，高度随图片比例变化，不裁切原图。根据2026-11-13验收反馈，移除输入区域外框和内部固定高度视口：图片完整占据其比例高度，加号、继续／跳过／梦境状态及保存提示随新增图片一起向下移动。长文、多图或长图超出屏幕时只滚动整页，不再在输入区内单独滚动图片。

点击缩略图进入黑色大图页，可缩放；左上角关闭，右下角垃圾桶移除。长按缩略图后选择「删除图片」也可移除。移除不删除系统相册原件。等待「已保存」后再退出、重开验证。

**只有图片、没有文字也算一条记录。** 历史以「图片记录」显示无正文无反馈的日期，月历有圆点；统计活动按“正文非空或图片非空”的日期去重，同日多图仍只算一天。状态、评分、因素仍按独立反馈计算，不从图片推断。清空文字保留图片，移除最后图片后仍保留已有正文、反馈或完成标记；所有字段均空才删除日期行。

## 系统权限

使用 Flutter 官方 [image_picker](https://pub.dev/packages/image_picker) 1.2.4。仅从相册选图，不提供拍照，不申请相机或麦克风。iOS 配置 `NSPhotoLibraryUsageDescription`，选图采用插件默认的系统授权流程。Android 不增加广泛媒体读取权限，由系统选择器授予所选照片访问；部分系统直接显示照片选择器，不另弹传统权限框。App 不添加相册权限说明、拒绝权限引导或设置弹窗，取消/拒绝不影响文字记录。

## 数据流与升级

`正文组件 → DreamEditorController → DreamRepository / IImageAttachmentService`。数据库 v3 在原 `dream_records` 表追加 `images` JSON 列，保存相对文件名、宽高；v1 先补反馈列再补图片列，v2 只补图片列。旧正文、日期、UTC 时间戳、反馈不改写，不删库。

原图复制到应用支持目录的 `dream_images/`，校验可解码尺寸，临时文件 flush 后原子改名，之后才允许写数据库引用。SQLite 不保存相册临时路径或沙盒绝对路径；缩略图按显示宽度解码，大图使用原文件。取消或文件导入失败不改草稿。

图片快照复用正文的串行保存、失败保留与导航等待；文字/移除保持 800ms 防抖，新增图片复制成功后立即提交当前完整草稿。选图时日期导航等待，返回结果属于最初日期。省略 `save(images:)` 保留现有附件，显式 `[]` 才清空。先提交 DB，再清理被移除文件；清理失败最多留下私有孤立文件，不误删仍引用的图片。

Android 选图前原子记录日期，Activity 被系统回收后通过 `retrieveLostData` 恢复；导入后的待提交文件名留在恢复日志，重试时幂等合并。只有包含该选择的快照已提交才确认日志，旧文字快照不会提前清除它。日志确认失败保留失败草稿并锁定图片移除，重试成功前不允许切日；这避免残留日志在重开后复活已删除图片。

## 验证与边界

自动测试覆盖真实 v1/v2 文件升级、跨连接关闭重开、删除 picker 临时源后原文件仍在、仅图历史/月历/统计、空字段规则、串行快照竞态、失败重试、读取失败禁写、Android lost-data 日期恢复、普通及两倍/三倍字号的菜单位置、图片等宽比例、黑底大图与长按移除。实际命令、基线及最终结果见 [项目状态](PROJECT_STATUS.md)。

人工验收建议：

1. 旧记录仍可查看和编辑；进入正文，点加号，从相册选择横图、竖图，检查菜单位置和缩略图比例。
2. 点图检查黑底、缩放及右下角垃圾桶；长按另一张检查移除。
3. 不输入文字，仅添加图片，等「已保存」，退出重开，再从历史/月历找回同日图片。
4. 清空文字仍保留图；移除最后图时已有反馈保留。统计中的状态、评分、因素不因图片被推断或改变。

当前无链接、图像搜索、图片导出、云同步、图片总量限制或孤立文件自动回收；不压缩或重编码原图，原图可能包含相册原有元数据。系统强杀不能保证尚未完成复制/落库的操作；卸载或清除数据会删除私有图片。真机及 Android 逐项人工验收待后续安排。iOS 模拟器的 HEIC 选择存在插件已知限制，验收先用 JPEG/PNG，HEIC 留真机实测。
