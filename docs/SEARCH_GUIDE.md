# 梦境搜索说明

## 使用方式

首页右上角的放大镜（🔍）打开独立搜索页，并自动聚焦输入框、请求系统键盘。
输入关键词后停顿 300ms 自动搜索，无需再点击确认。中文输入法组词期间等待确认；
键盘上的搜索键可以收起键盘。清空按钮会清除结果并重新聚焦输入框。

搜索梦境正文中的连续文字，忽略关键词首尾空白及 ASCII 英文字母大小写；
中文、emoji、标点、`%`、`_`、反斜线均按字面匹配。不支持拼音、分词、正则、
模糊纠错或日期筛选。空关键词不列出全部历史，无匹配与查询失败有不同提示。

结果按梦境所属日期从近到远排列，预览展示命中位置附近的文字；点击后回到该日
编辑器，读取完整原文。取消搜索返回上一层不会改变原来选中的日期或正文。

## 数据流与取舍

```text
首页 🔍 → flushPendingSave → /search
输入框 → dreamSearchProvider(keyword) → IDreamSearchRepository
       → DriftDreamSearchRepository → 既有 dream_records 表
选择结果 → pop<DateTime> → 编辑器 selectDate → 原有读取/保存流程
```

- UI 只处理输入、焦点与展示，不直接读取数据库。
- 搜索使用原数据库连接、表和 schemaVersion 1，没有新增依赖、索引或迁移。
- LIKE 模式使用绑定参数，转义通配符后按字面匹配，不拼接用户输入到 SQL。
- family 为每个关键词隔离异步状态；换词/清空/离开后，旧查询不能覆盖当前结果。
  已开始的只读 SQL 可以完成，已销毁的延迟任务不会再发起查询。
- 每次进入重新查询，不缓存搜索历史或保存关键词，不上传梦境或搜索内容。
- 导航前循环等待最新草稿，包含 await 间隙到达的末尾输入；保存失败时留在
  编辑器，保留草稿并使用原有重试入口。正文清空时先完成删除，再搜索。
- 当前无分页、全文索引或大数据量性能保证；普通连续文本匹配会扫描原表。
  若未来数据量增加，再根据实际测量设计索引或分页，不提前改表。

## iOS 用户验收建议

1. 在首页点击 🔍，检查搜索页和键盘是否自动出现。
2. 用人工测试梦境的中文关键词搜索，再用英文大小写、emoji 或标点搜索。
3. 快速换词和清空，确认旧结果不会重新出现；无匹配时查看提示。
4. 点击结果，确认日期、完整正文、换行和空格正确；返回今天继续编辑。
5. 在编辑器输入人工测试内容后立即搜索，确认新内容可找到；清空该测试记录
   后再次搜索，确认结果消失。已有个人记录不必为测试而删除。
6. 返回再进入搜索，检查键盘仍自动出现。模拟器若启用硬件键盘，可能只显示
   输入光标；可在模拟器的键盘设置中关闭硬件键盘连接（不同 Xcode 版本菜单不同）。

Android 本轮只做构建检查；双端真机键盘与性能回归仍待后续验证。
