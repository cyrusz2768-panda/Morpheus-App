# 梦境月历：记录标记与日期联动

更新日期：2026-11-08。当前进度、验证结果和交接入口以 [项目状态](PROJECT_STATUS.md) 为准；本页说明月历实现和回归方法。

## 使用方式

编辑页右上角的日历按钮现在进入“梦境月历”。保持现有主题和编辑器，增加这些能力：

- 日期下方的圆点表示这一天有非空梦境记录；图例同时说明含义。
- 月历保留“有梦境记录”图例，移除非空月份底部重复的操作说明。
- 点击日期，回到原来的编辑器读取该日内容；没有记录时可以补记。
- 左右切换月份；“回到今天”将月历定位到本月和今天。
- “选择日期”保留原生中文快速选择器，便于跳转到较早日期；确定后直接打开对应记录，取消时仍留在月历。
- 可以选择 1900-01-01 至今天，未来日期不可选择。今天和当前选中日期有各自的视觉/语义状态。

新增记录后再次进入月历，对应日期出现圆点；清空正文并保存删除后，圆点消失。记录文字的普通修改不会改变所属日期，也不会生成重复圆点。

## 语言与文件

本轮使用 **Dart** 编写页面、状态和数据访问，Flutter 绘制月历网格，Riverpod 管理每月订阅，Drift 将查询转换成 **SQL** 并监听 SQLite 变化。没有新增依赖或原生平台插件，数据库表和版本保持不变。

## 圆点如何与记录保持一致

```text
用户输入或清空正文
  → 原编辑器保存/删除 SQLite 中的记录
  → Drift 通知月历查询数据已变化
  → 每月 Provider 收到新日期集合
  → 月历增加/保留/移除圆点
```

圆点直接来自梦境表，不另建标记表。这样不会出现“梦境删了，标记副本却没删”的同步问题。

查询范围是“本月月初（包含）到下月月初（不包含）”，不是固定加 30 天。SQLite 先按日期主键筛选月份，再返回日期和用于空白判断的正文，正常数据最多 31 行，不加载整份多年历史。Dart 的 `trim()` 排除旧版本可能留下的换行、制表符等纯空白记录。

日期键沿用 `yyyy-mm-dd`，不转换成 UTC 午夜时间戳；梦境仍属于用户选择的日历日期。查询与页面都使用日历年月计算边界，支持短月、闰日和跨年。

`StreamProvider.family` 区分不同月份，`autoDispose` 在翻月或离开后取消旧订阅。底层仍是 App 共用的数据库连接，不随月历关闭而删除数据或关闭整个数据库。

读取失败会明确提示并提供重试，不能把故障当成“这个月没有记录”，也不会把上个月的圆点留在新月份里。

## 草稿保护

打开月历前先等待编辑器最新草稿写入成功，再显示已提交的日期标记。等待期间若输入法交付末尾文字，会继续保存这一版，再执行导航。保存失败则留在编辑器，保留原日期、正文与重试入口。

月历页只返回所选日期，不自行读写正文。返回后仍由原 Controller 安全切换日期；数据库读取失败时保持原有的禁用编辑与重试机制。

## 验收步骤

以下步骤用于月历功能的人工回归，本轮按用户要求仅打开 iOS 模拟器：

1. 点击日历图标，确认月历能显示已有记录日期的圆点。
2. 点击某个圆点日期，确认打开该日正文，其他日期内容不被改写。
3. 选择一个过去的空日期，输入测试内容，立即重新打开月历；对应日期应出现圆点。
4. 回到这条测试记录，清空正文，再进入月历；对应圆点应消失，其他日期标记保持。
5. 切换上个月/下个月，验证圆点只属于当前显示月份；点击“回到今天”返回本月。
6. 用“选择日期”打开快速选择器，验证确定和取消；未来日期保持不可选。
7. 保存后完整退出、重新打开 App，再查看月历，确认记录与标记均保留。

自动测试使用内存仓库或独立临时 SQLite 文件，不改写模拟器中的个人梦境。最近的月历与菜单更新通过 134 项测试、静态分析、格式检查、iOS 模拟器构建启动及 Android ARM64 调试构建；本轮 Android 未进行人工验收，真机行为仍待验证。
