# 周、月、年统计与底部导航

2026-11-10 首版。Android / iOS 使用同一套 Dart 页面与本地数据库。

## 统计口径

- 周为周一至周日；月、年为自然月、自然年，可翻阅历史周期并回到本期。
- 每个有非空白正文的梦境所属日期计一天，不按创建或修改时间归类。补记过去的梦只影响过去所属周期；同日修改仍计一天；清空并保存后删除，统计随之减少。
- 当前周期只统计截至今天的日期。覆盖率 = 记录天数 / 本期已经过的天数，包含今天，不把未来日期算作漏记。
- 周末／平日的分母是本期有记录的天数；周六、周日视为双休日，周一至周五为平日。不接入法定节假日和调休数据。没有记录时占比显示“—”，显示百分比取互补整数以保持合计 100%。
- 趋势：周按日；月按周一分组，首尾裁切在本月内；年按月。数值表示记录天数。未来分组显示“—”，年图可横向滚动。
- 当前周期与上期相同经过天数比较，上期较短时取完整上期；已结束的历史周期比较两个完整周期。只显示天数差，不计算增长百分比。
- 好梦／噩梦尚无记录字段，首版不显示该比例，不推测梦境情绪。

## 页面与数据流

底部实色圆角导航提供「记录、统计、日历」，沿用现有紫色主题，不使用液态玻璃。记录页原有搜索、历史、菜单及快捷选日仍可使用；快捷选日继续作为全屏选择器。底栏日历点选日期后回到原编辑器查看或补记。Android 系统返回从统计／日历回记录。

`IStatisticsRepository` → `DriftStatisticsRepository` 查询既有 `dream_records` 的日期投影；`statisticsDatesProvider` 管理订阅，`DreamStatistics` 聚合，页面只渲染数据。查询范围为本期加上期，正文仅在仓库内用于过滤历史空白行，不向统计页传递正文。沿用数据库版本 1，无新表、依赖或持久化统计缓存。

底栏、顶栏与日历选日共用导航令牌。离开记录前 unfocus，再循环等待最新草稿落盘；保存失败留在原页保留输入。通知回当天会撤销旧导航意图并持有锁，避免旧 Future 完成后抢回页面。二级搜索／历史／提醒设置保持原来的 push/pop 返回流程。

当前日分母在本地午夜或从后台返回时更新；编辑器既有“不会跨午夜自动切换正在编辑日期”的行为不变。读取失败显示错误与重试，不显示为零记录。

按本轮用户明确要求，新增统计与底栏中文文字暂放在页面中；用户验收通过后再同步到 `app_zh.arb` 并执行 `flutter gen-l10n`。既有资源继续使用，不能将本次临时例外当作后续默认约定。

## 人工验收建议

1. 在记录页输入人工测试内容，立即点统计：记录天数应增加，回记录可看到完整正文。
2. 修改同一天正文再进入统计，天数不增加；清空后进入统计，该天数移除。
3. 从底栏日历进入上月，选择日期补记；上月统计增加，本月不因今天补记而增加。
4. 切换周／月／年，检查日期范围、上一周期、下一周期禁用、回到本期及趋势图。检查周末／平日比例和统计说明。
5. 在统计／日历收到提醒通知后应回到当天记录。通知的真机长期后台行为仍沿用后续专项验收。
6. 保持原安装与数据，看到“已保存”后完整退出重开，核对记录和统计。不要卸载、删库或清除模拟器。
