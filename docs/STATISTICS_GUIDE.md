# 状态、睡眠自评与因素统计

2026-11-12 在 `871725d` 上升级，随后基于本地 `d436207` 按验收反馈调整图表。Android / iOS 共用 Dart 实现。统计页不展示记录天数、梦境次数、覆盖率、记录次数趋势或周末／平日指标。仅本地开发、测试并打开 iOS 模拟器，等待本轮验收后再安排上传。实际检查证据见 [项目状态](PROJECT_STATUS.md) 与 [日志](Log.md)。

## 页面内容与口径

- 周从周一至周日，月、年使用自然周期。当前周期只纳入截至今天的数据，未来日期不作为漏填；历史周期使用完整范围。数据继续按醒来后记录的当天归属，不因“昨晚”减一天。
- 周状态图为七列四行的着色网格：横轴周一至周日，纵轴好梦／噩梦／没记住／没做梦，每列最多一个着色格。未填写及未来日期留空，不推断成没做梦；周图不使用环图。月、年仍使用五类状态环图：好梦黄色、噩梦紫色、没记住浅棕色、没做梦蓝灰色、未填写状态灰色。没有记录、跳过状态以及旧版只有正文的日期均保持未填写，不能从正文推测状态。
- 好梦／噩梦百分比只比较这两类明确反馈，不包含没记住、没做梦或未填写。两项百分比取互补整数，合计 100%。没有可比较反馈就显示未知提示，不伪造比例。
- 定性分析只描述“已分类的梦境”：只有好梦／只有噩梦时使用“都是”；好梦比例在 40%–60%（含边界）时使用“频率差不多”；其余使用好梦或噩梦“占多数”。这不代表所有夜晚都已填写。浏览历史周／年时用“这一周／这一年”，不误称本周／今年。
- 睡眠自评平均分只计算真实填写的 1–5 分，保留一位小数，不按梦境好坏推算。没有评分为 `null`，显示“—”，不视为 0 分，也不展示评分天数。
- 评分趋势：周按日，月从1日开始固定分为1–7、8–14、15–21、22–28及29–月底，年按月显示平均分。普通二月只有四组，其他月份的尾组按实际月尾截断。总均分按每日评分计算，不把不同样本量的分组均值再等权平均。空分组留空并中断折线，不跨空值补线；未来分组读屏为“尚未开始”，已过但无评分为“未填写”。纵轴固定为1–5分，三种周期的整张折线图始终使用卡片可用宽度，无需横向滑动。轴刻度使用紧凑标注；长按刻度或读屏可取得完整日期及准确均分。
- 因素独立于正文、状态和评分保存。每日期每个已选因素最多计一次，按频次降序取最多三项，不显示次数。少于三项只展示实际项；第三位同频时按每日选项顺序稳定取舍，不额外扩展数量。
- 因素摘要表达用户主观反馈，不推断客观因果。前三项包含“不确定”时使用专门句式：只选不确定时说明尚不确定，混合选择时列出具体因素并说明也有不确定反馈。

## 数据流与既有保护

`IStatisticsRepository.watchRecords(window)` → 单一数据库投影 → `statisticsRecordsProvider` → `SleepFeedbackStatistics` → 同一统计页面。

SQLite 先按日期主键读取本期与上期范围（最多两年），投影日期、正文存在性、状态、可空评分与因素，不将正文传到统计页面。新旧指标只使用一份快照，反馈修改／清除／删除后实时更新。内部保留原正文日期查询和分桶辅助模型以兼容既有调用，但页面不再展示天数统计。

使用现有 schema v2，不新增依赖、表、迁移或持久化统计缓存。旧梦境的新反馈保持未填写。仅有全部跳过完成标记的日期，不被推断为没做梦、0 分或任何影响因素。

加载、切期、重试和读取失败统一作用于整份反馈快照，失败时隐藏旧图，不把故障伪装成零值。底栏与通知跳转仍先保存最新正文和反馈；保存失败留在原页供重试。午夜和返回前台时重新计算截止日期，但不自动切换编辑器正在编辑的日期。

## 每周回顾复用

现有每周回顾通知直接打开本统计页的当前自然周，自动包含状态图、定性总结、评分均值／趋势和前三因素。没有另一套回顾数据或重复计算，月／年历史浏览收到回顾通知时仍回到点击时所在周。通知文本继续为通用提醒，不把睡眠反馈或梦境内容放入系统通知。详见 [每周回顾说明](WEEKLY_REVIEW_GUIDE.md)。

## 验收建议

请使用人工测试内容，保留原安装和数据，不卸载或清空模拟器。

1. 分别填写四种梦境状态，另留一个未填写日期；周图检查对应星期和状态位置着色、未填及未来空白；月年检查环图与图例。页面不直接显示次数或记录天数。
2. 好梦／噩梦数量接近、单一类别、无明确类别时检查定性总结；旧正文不应自动变成好梦，没做梦不应混同灰色未填写。
3. 只填评分不填正文也可统计。间隔日期填写 1–5 分，检查平均分和趋势；未填不变 0，图线在缺失处断开。切换周／月／年及历史周期，检查日期和未来分组。
4. 多选因素后查看前三项摘要，少于三项不补齐、不展示数字；只选“不确定”时检查专门措辞。修改或清除反馈后统计应更新。
5. 从旧月／年浏览状态点击每周回顾通知，检查回到最新自然周且复用以上内容。实际系统通知送达、锁屏与长期后台不因自动导航测试而视为验收通过。
6. 等“已保存”后完整退出重开，核对状态、评分和因素恢复。页面可上下查看各卡片，周网格及周／月／年评分图均不需要横向滑动；窄屏和大字号下检查首尾日期及所有数据点完整可见。

自动测试覆盖聚合边界、真实数据库监听与重开、未知值、注入文案、错误重试、窄屏大字号及回顾导航。自动测试与原生构建不等同于用户或真机人工验收。
