# 每周统计回顾通知

2026-11-10 首版；2026-11-11 根据反馈整理设置界面。Android / iOS 共用 Dart 实现，无新增依赖、数据库表或版本迁移。当前验证与人工验收状态见 [项目状态](PROJECT_STATUS.md)。

## 使用与周期口径

2026-11-12 统计升级及图表验收调整后，回顾入口仍复用同一个统计页，展示周状态着色网格与定性分析、睡眠自评均值和整宽趋势、前三因素摘要，不直接展示记录天数或梦境次数。网格未填写或未来日期留空，月年仍用环图；独立反馈的统计口径见 [统计说明](STATISTICS_GUIDE.md)。通知调度、默认星期／时间及保存保护保持原有行为。

从记录页左上角三条杠菜单 →「通知设置」进入。「每日提醒」与「每周回顾」的标题位于各自圆角卡片外，卡片首行均为「消息通知」独立开关；回顾默认关闭，默认星期日 21:00，可更改星期与时间。开启后展开提醒日／时间，关闭后隐藏细项，原时间和星期仍然保留。修改自动保存，重开 App 后保留；关闭回顾只取消每周任务，每日提醒继续按原设置工作。

用户已确认周日即可回顾当周，而非等待周一。点击回顾通知打开**点击时所在自然周（周一至周日）**，页面展示完整起止日期和截至当天的记录。例：2026-11-15 周日点击显示 11 月 9–15 日；延迟至 11 月 16 日点击则显示最新的 11 月 16–22 日。当前周未来日期仍不计入已过天数，不宣称周日晚已包含尚未发生的记录。

通知使用通用标题「梦境周回顾」和正文「回顾一下这一周做过的梦吧」，不包含梦境正文或统计数据。点击前先收起输入法，等待最新草稿保存；保存失败留在原页保留草稿，可重试保存后手动进入统计。即使正在查看旧周、月或年，也会切回最新周。每日记录提醒仍打开当天记录。

页面已移除测试按钮、说明小字及系统通知状态栏。两项提醒共享系统通知权限，授权不等于开启开关；用户尝试开启时查询／申请权限，被拒绝后在当次错误提示旁提供「去系统设置」，不常驻权限区域。拒绝权限仍可记录、搜索和查看统计。

## 实现与持久化

`ReminderSettingsPage` → `ReminderController` → `IReminderSettingsStore` / `IReminderNotifications`。页面不读写文件、数据库或直接调用原生通知。配置继续存入私有 `settings/reminders.json`，在 notifications 内增加：

```json
{
  "weeklyEnabled": false,
  "weeklyWeekday": 7,
  "weeklyHour": 21,
  "weeklyMinute": 0
}
```

星期为 Dart 约定的 1（周一）至 7（周日）。缺失字段使用默认值，不覆盖旧版每日开关、时间及两个已读状态；显式损坏或越界字段报告读取失败，不擅自重写文件。设置更改串行处理，先同步两项日程，再原子保存 JSON；失败尝试恢复之前两项调度。启动／返回前台重新读取权限与设备时区，同步用户已保存的选择。

每日任务 ID 1101 与周回顾 1103 独立；底层测试 ID 1102/1104 只保留用于平台回归，页面无测试入口。周 payload 为 `morpheus:weekly-statistics`，不固化首次发送日期。插件使用 [`DateTimeComponents.dayOfWeekAndTime`](https://pub.dev/documentation/flutter_local_notifications/latest/index.html) 按当地星期及时间重复。日历计算覆盖跨年及夏令时；首次候选时分因夏令时不存在时，选用之后存在该时分的星期作为模板，避免永久偏移一小时。

App 接收带目标的冷启动／运行中点击，捕获日期和序号，等待编辑器加载与草稿保存。后到点击替代旧导航目标；统计路由使用请求标识重建页面，确保重复点击可撤销旧月／年浏览状态。通知内容不读取梦境正文，点击沿用既有保存链路保护草稿，不存储另一份统计结果。

新增文字与语境说明保存在 `lib/l10n/app_zh.arb`，页面通过 `context.l10n`、Controller / 平台服务通过注入资源读取；生成目录不提交。当前仍仅中文。

## iOS 人工验收

1. 保留原安装与数据，从菜单进入通知设置，确认卡片外标题为每日提醒／每周回顾，卡片首行为消息通知。开启回顾展开默认周日 21:00，关闭后折叠细项，每日开关应保持原样。
2. 更改回顾星期和时间，返回后重进；完整退出重开，确认选择保留。关闭回顾，确认每日设置不变。
3. 允许系统通知并开启回顾，将星期设为今天、时间设为几分钟后再切到后台；点击收到的回顾通知，应进入周统计且显示明确起止日期。可在旧月／年统计中再次等待定时通知，点击应回到最新周。
4. 编辑专门的人工测试正文，尚未等到防抖保存即点击回顾通知；应先保存，返回记录可看到完整文字。保存失败的故障注入由自动测试覆盖。
5. 定时验收结束后恢复周日 21:00 或关闭，再完整退出重开，确认星期／时间仍保留；关闭状态只显示消息通知开关。
6. 同时开启每日提醒和回顾，分别关闭其中一项，检查另一项仍按已保存选择工作。拒绝系统权限时应展示补救入口，梦境编辑继续可用。

Android 本轮执行构建与插件桥接自动测试，不启动模拟器人工验收。普通通知可能因系统节电延迟；静音／专注模式、真机长期后台、重启和旅行时区等仍需后续实测。原生配置及系统限制沿用 [提醒说明](REMINDERS_GUIDE.md)。构建和自动测试通过不等同于人工验收通过。2026-11-11 用户已明确确认本轮 iOS 模拟器验收通过并授权提交推送；未提供额外逐项验收清单，不扩展为 Android 或真机验证。
